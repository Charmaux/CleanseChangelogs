# Cleanse v1.0 — Initial Release

Cleanse v1.0 is here! 🎉 

The first official release of Cleanse brings powerful server cleaning, backup, restore, and protection tools designed to help keep your Discord server organized, safe, and under control.

### 🧹 Server Cleaning

* Added powerful message cleaning and bulk purge tools.
* Quickly remove unwanted messages from channels.
* Support for targeted and configurable cleanup.
* Built with safety checks to help prevent accidental actions.

### 📦 Server Backups

* Added complete server backup creation.
* Backups include supported channels, roles, permissions, emojis, stickers, and other server configuration.
* Every backup receives a unique **Backup ID**.
* Added `/backup create` to create backups.
* Added `/backup list` to view stored backups.
* Added `/backup delete` to remove backups.
* Added `/backup restore` to restore a server from a backup.
* Added backup storage limits for different plans.

### 🔄 Automatic Backups

* Added scheduled automatic backups for Premium servers.
* Choose between:

  * Hourly
  * Daily
  * Weekly
* Added the ability to disable automatic backups.
* Automatic backups are safely tracked and logged.



### ⭐ Premium

* Added Premium backup features.
* Premium servers can access automatic backup schedules.
* Added detailed backup information.
* Added backup export functionality.
* Increased backup storage limits for Premium servers.

### 📋 Backup Management

* Added detailed backup information including:

  * Backup ID
  * Status
  * Type
  * Size
  * Channels
  * Roles
  * Emojis
  * Stickers
  * Creator
* Added JSON backup exports for Premium servers.
* Added confirmation buttons for destructive backup actions.
